# 内容规划工具

## 概述

内容规划工具帮助在生成知识库前系统化规划内容结构和来源，确保内容准确、可靠、有价值。

---

## 步骤1: 主题分解

### 任务：将主题分解为核心维度

**分解维度模板**：

| 维度 | 关键问题 | 重要性 |
|------|----------|--------|
| 核心概念 | 什么是xxx？定义、特征、原理 | ★★★★★ |
| 历史背景 | 如何产生？如何演变？关键事件 | ★★★★ |
| 现实应用 | 如何应用？应用场景？案例 | ★★★★ |
| 与普通人关系 | 对普通人有什么影响？应对策略 | ★★★★★ |
| 与国家/社会关系 | 对国家/社会有什么影响？ | ★★★ |
| 争议点 | 有哪些争议？不同观点？ | ★★★ |
| 未来趋势 | 未来发展方向？ | ★★ |

### 核心问题列表模板

**填写指南**：

```
核心问题1: [问题内容]
- 需要回答什么？
- 从哪个角度回答？
- 回答深度：概述/详细

核心问题2: [问题内容]
- ...

核心问题3: [问题内容]
- ...
```

## 步骤2: 知识来源识别

### 任务：识别可靠的知识来源

**知识来源分类**：

| 来源类型 | 特点 | 适用内容 | 可信度 |
|----------|------|----------|--------|
| 学术来源 | 学术论文、专业书籍、权威机构报告 | 核心概念、历史背景 | ★★★★★ |
| 官方来源 | 政府数据、官方统计、政策文件 | 数据、政策、官方信息 | ★★★★★ |
| 媒体来源 | 新闻报道、深度报道、专题文章 | 现实应用、案例 | ★★★ |
| 实践来源 | 行业实践、案例分析、经验分享 | 应用方法、实践技巧 | ★★★ |
| 网络来源 | 百度百科等网络资源 | 基础信息、补充内容 | ★★ |

**评估维度**：

| 维度 | 评估标准 | 分值 |
|------|----------|------|

| 时效性 | 信息是否最新？ | 1-5分 |
| 准确性 | 信息是否准确？ | 1-5分 |
| 完整性 | 信息是否完整？ | 1-5分 |

## 使用建议

### 规划时机
- 在开始生成知识库前进行规划
- 规划时间建议：10-20分钟

### 规划原则
- 核心内容优先规划
- 来源可信度优先考虑
- 内容深度合理分配

### 规划调整
- 生成过程中可根据实际情况调整
- 发现新来源时及时补充
- 内容深度可根据需要调整
