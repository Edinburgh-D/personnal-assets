## 一、三大热点趋势方向

### 1.1 热点复盘与沙盘推演

**目标**：从热点中学习，提升趋势判断能力

**内容类型**：
- 热点复盘：分析热点事件的全过程
- 沙盘推演：模拟不同决策的结果
- 教训总结：提炼可复用的经验

**示例主题**：
- 《ChatGPT爆发复盘：从0到1亿用户的路径》
- 《小红书爆款推演：如何复制成功》
- 《AI投资热点复盘：机会与风险》

---

### 1.2 前沿生产力实测

**目标**：第一时间验证新工具，建立工具评测权威

**内容类型**：
- 工具评测：深度评测新工具
- 效率对比：对比不同工具效率
- 使用指南：详细使用教程

**示例主题**：
- 《Claude实测：与ChatGPT的效率对比》
- 《AI Agent工具评测：5个工具实测》
- 《Perplexity实测：AI搜索的新可能》

---

### 1.3 全球商业趋势翻译官

**目标**：第一时间翻译全球趋势，建立信息优势

**内容类型**：
- 趋势翻译：翻译全球商业趋势
- 本土化解读：结合本土市场解读
- 应用建议：提供本土应用建议

**示例主题**：
- 《美国AI创业趋势：本土化机会》
- 《欧洲银发经济：中国市场的启示》
- 《硅谷情绪商业：新商业模式》

## 二、热点捕捉流程

### 2.1 信息收集阶段

**工具**：AP News、Hacker News、Ground News、LinkedIn

**步骤**：

1. **新闻浏览**
   - 使用 Mobile Claw 浏览 AP News（全球新闻）
   - 使用 Mobile Claw 浏览 Hacker News（技术趋势）
   - 使用 Mobile Claw 浏览 Ground News（多视角新闻）
   - 使用 Mobile Claw 浏览 LinkedIn（商业动态）

2. **热点识别**
   - 使用 ChatGPT 分析热点价值：
     ```
     请分析以下新闻的热点价值：
     新闻：{新闻内容}
     评估维度：
     - 时效性
     - 影响范围
     - 个人匹配度
     - 内容产出价值
     ```

3. **热点分类**
   - 即时热点：需要立即跟进
   - 趋势热点：可以深度分析
   - 长期热点：可以系列追踪

---

### 2.2 热点分析阶段

**工具**：ChatGPT、Claude

**步骤**：

1. **深度分析**
   - 使用 ChatGPT 进行热点分析：
     ```
     请深度分析以下热点：
     热点：{热点内容}
     分析维度：
     - 背景：热点产生的原因
     - 过程：热点的发展过程
     - 影响：热点的影响范围
     - 趋势：热点的未来走向
     ```

2. **多视角对比**
   - 使用 Ground News 获取多视角报道
   - 使用 ChatGPT 对比不同视角

3. **沙盘推演**
   - 使用 ChatGPT 进行推演：
     ```
     请进行沙盘推演：
     热点：{热点内容}
     推演场景：
     - 如果{条件A}，结果会是？
     - 如果{条件B}，结果会是？
     - 最佳决策是什么？
     ```

---

### 2.3 内容产出阶段

**工具**：ChatGPT、Claude、Medium、小红书、Threads

**步骤**：

1. **内容撰写**
   - 使用 ChatGPT 撰写复盘报告
   - 使用 Claude 优化内容深度

2. **配图生成**
   - 使用 ChatGPT 生成配图

3. **平台发布**
   - 深度复盘 → Medium
   - 快速分析 → 小红书、Threads

## 十、热点捕捉技巧

### 1. 信息源管理

建立稳定的信息源：

- **AP News**：全球新闻第一时间
- **Hacker News**：技术趋势前沿
- **Ground News**：多视角对比
- **LinkedIn**：商业动态
- **Medium**：深度分析文章

### 2. 时效性管理

建立快速响应机制：

- 发现热点 → 30分钟内分析
- 确认价值 → 1小时内开始创作
- 内容产出 → 24小时内发布

### 3. 深度管理

确保分析深度：

- 不只描述，要分析原因
- 不只分析，要推演结果
- 不只推演，要提供建议

### 4. 多视角管理

确保视角全面：

- 使用 Ground News 对比不同报道
- 使用 ChatGPT 分析不同观点
- 结合本土视角解读

## 十二、进阶技巧

### 1. 热点预测

建立热点预测能力：

- 分析历史热点规律
- 使用 ChatGPT 预测趋势
- 提前准备内容框架

### 2. 系列追踪

对重要热点进行系列追踪：

- 第一篇：热点概述
- 第二篇：深度分析
- 第三篇：后续发展
- 第四篇：复盘总结

### 3. 联动分析

将热点与个人方向联动：

- 热点 → 内容输出方向
- 热点 → 投资方向
- 热点 → 能力延展方向

### 4. 数据驱动

用数据支撑热点分析：

- 使用 ChatGPT 收集数据
- 使用 Claude 分析数据
- 图表化展示数据
