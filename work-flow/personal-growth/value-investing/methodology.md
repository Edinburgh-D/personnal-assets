# 价值投资方法论

> 公开投资实盘/逻辑库、普通人财务自由路线图、商业模式排雷

---

## 一、三大价值投资方向

### 1.1 公开投资实盘/逻辑库

**目标**：建立投资逻辑体系，展示投资能力

**内容类型**：
- 投资逻辑：投资决策的底层逻辑
- 实盘记录：公开的投资记录（仅研究，不实际操作）
- 逻辑库：可复用的投资逻辑

**注意**：仅进行投资研究和逻辑构建，不进行实际投资操作（Mobile Claw禁止金融类App操作）

---

### 1.2 普通人财务自由路线图

**目标**：为普通人提供财务自由路径

**内容类型**：
- 路线图：财务自由的完整路径
- 阶段规划：不同阶段的财务目标
- 执行方法：具体的执行方法

---

### 1.3 商业模式排雷

**目标**：识别商业模式风险，避免踩坑

**内容类型**：
- 排雷报告：分析商业模式风险
- 风险清单：常见商业模式风险
- 防坑指南：避免踩坑的方法

---

## 二、投资逻辑构建流程

### 2.1 信息收集阶段

**工具**：AP News、Ground News、ChatGPT

**步骤**：

1. **新闻收集**
   - 使用 Mobile Claw 浏览 AP News（财经新闻）
   - 使用 Mobile Claw 浏览 Ground News（多视角财经新闻）
   - 收集行业动态、公司新闻

2. **信息筛选**
   - 使用 ChatGPT 分析信息价值：
     ```
     请分析以下财经信息的投资价值：
     信息：{财经新闻}
     分析维度：
     - 对行业的影响
     - 对公司的影响
     - 投资机会
     - 投资风险
     ```

3. **信息记录**
   - 将有价值信息保存到知识库
   - 标记投资逻辑方向

---

### 2.2 投资分析阶段

**工具**：ChatGPT、Claude

**步骤**：

1. **行业分析**
   - 使用 ChatGPT 进行行业分析：
     ```
     请分析以下行业的投资价值：
     行业：{行业名称}
     分析维度：
     - 行业现状
     - 行业趋势
     - 投资机会
     - 投资风险
     ```

2. **公司分析**
   - 使用 ChatGPT 进行公司分析：
     ```
     请分析以下公司的投资价值：
     公司：{公司名称}
     分析维度：
     - 公司现状
     - 公司优势
     - 公司风险
     - 投资建议
     ```

3. **逻辑构建**
   - 使用 Claude 构建投资逻辑：
     ```
     请构建以下投资方向的底层逻辑：
     方向：{投资方向}
     逻辑维度：
     - 核心逻辑
     - 支撑因素
     - 风险因素
     - 决策框架
     ```

---

### 2.3 逻辑验证阶段

**工具**：ChatGPT、Ground News

**步骤**：

1. **多视角验证**
   - 使用 Ground News 获取多视角报道
   - 使用 ChatGPT 对比不同视角

2. **历史验证**
   - 使用 ChatGPT 分析历史类似案例：
     ```
     请分析历史上类似的投资逻辑：
     逻辑：{投资逻辑}
     分析：
     - 类似案例
     - 成功因素
     - 失败因素
     - 教训总结
     ```

3. **风险验证**
   - 使用 ChatGPT 分析潜在风险：
     ```
     请分析以下投资逻辑的潜在风险：
     逻辑：{投资逻辑}
     风险维度：
     - 市场风险
     - 行业风险
     - 公司风险
     - 操作风险
     ```

---

### 2.4 逻辑沉淀阶段

**工具**：ChatGPT、Medium、小红书

**步骤**：

1. **逻辑文档化**
   - 使用 ChatGPT 撰写投资逻辑文档
   - 结构化整理逻辑框架

2. **逻辑发布**
   - 发布到 Medium（深度分析）
   - 发布到小红书（精简版）

3. **逻辑更新**
   - 根据市场变化更新逻辑
   - 定期复盘逻辑有效性

## 九、风险控制

### 1. 不进行实际投资

- 仅进行投资研究和逻辑构建
- 不使用金融类App（Coinbase、Binance、PayPal等禁止）
- 不提供具体投资建议

### 2. 逻辑验证

- 每个投资逻辑需经过多视角验证
- 需要有历史案例支撑
- 需要有风险分析

### 3. 内容合规

- 不提供具体投资建议
- 不承诺投资收益
- 强调风险提示
