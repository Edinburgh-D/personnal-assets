## 三、10小时快速破局法

### 3.1 破局流程

**工具**：ChatGPT、Claude、Hacker News、Medium

**步骤**：

**第1-2小时：信息收集**
- 使用 Hacker News、Medium 收集领域信息
- 使用 ChatGPT 分析领域核心概念

**第3-4小时：框架构建**
- 使用 ChatGPT 构建领域框架
- 使用 Claude 优化框架深度

**第5-6小时：快速实践**
- 设计最小实践任务
- 完成实践验证

**第7-8小时：输出验证**
- 使用 ChatGPT 辅助输出内容
- 发布到 Medium、小红书
- 收集用户反馈

**第9-10小时：复盘优化**
- 使用 ChatGPT 复盘破局效果
- 优化破局方法
- 制定后续计划
