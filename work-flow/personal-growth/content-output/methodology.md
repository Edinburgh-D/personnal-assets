## 一、三大内容输出方向

### 1.1 底层逻辑专栏

**目标**：建立个人知识体系，展示深度思考能力

**内容类型**：
- 概念解析：深入解析核心概念
- 方法论：可复用的方法论体系
- 案例分析：真实案例分析
- 思考框架：通用思考框架

**示例主题**：
- 《认知框架：如何建立个人知识体系》
- 《决策模型：从直觉决策到系统决策》
- 《学习曲线：高效学习的底层逻辑》
- 《影响力构建：从0到1000粉丝的方法论》

---

### 1.2 行业深度白皮书

**目标**：建立行业权威，提供专业价值

**内容类型**：
- 行业现状分析
- 趋势预测
- 竞品分析
- 实施建议

**示例主题**：
- 《2025年AI Agent行业白皮书》
- 《情绪商业：银发经济的新机会》
- 《AI Workflow架构师：新职业的诞生》
- 《个人品牌变现：从0到月入10万的路径》

---

### 1.3 长尾搜索内容

**目标**：获取持续流量，建立SEO资产

**内容类型**：
- 问题解答型：回答常见问题
- 工具教程型：工具使用教程
- 对比分析型：产品/方法对比
- 清单整理型：资源清单整理

**示例主题**：
- 《ChatGPT使用教程：从入门到精通》
- 《10个AI工具推荐：提升工作效率》
- 《Claude vs ChatGPT：哪个更适合你》
- 《2025年必备工具清单：50个效率工具》

## 二、内容创作流程

### 2.1 选题阶段

**工具**：ChatGPT、Claude、AP News、Hacker News

**步骤**：

1. **信息收集**
   - 使用 Mobile Claw 浏览 AP News、Hacker News
   - 收集热点话题、行业动态
   - 使用 ChatGPT 分析信息价值

2. **选题决策**
   - 使用 ChatGPT 评估选题价值：
     ```
     请评估以下选题的价值：
     - 搜索热度
     - 长尾价值
     - 个人匹配度
     - 竞争程度
     ```

3. **选题记录**
   - 将选题保存到选题库
   - 标记优先级和执行时间

---

### 2.2 构思阶段

**工具**：ChatGPT、Claude

**步骤**：

1. **框架构建**
   - 使用 ChatGPT 构建文章框架：
     ```
     请为以下主题构建文章框架：
     主题：{主题}
     类型：{专栏/白皮书/长尾}
     要求：
     - 核心观点明确
     - 结构清晰
     - 可操作性强
     ```

2. **素材收集**
   - 使用 Mobile Claw 浏览相关资料
   - 使用 ChatGPT 整理素材

3. **大纲确认**
   - 确认文章大纲
   - 标记关键论点

---

### 2.3 撰写阶段

**工具**：ChatGPT、Claude

**步骤**：

1. **初稿撰写**
   - 使用 ChatGPT 撰写初稿：
     ```
     请根据以下大纲撰写文章初稿：
     大纲：{大纲}
     风格：{轻松活泼/专业深度}
     字数：{字数要求}
     ```

2. **内容优化**
   - 使用 Claude 优化内容深度
   - 添加案例和数据支撑

3. **质量检查**
   - 检查逻辑连贯性
   - 检查可读性
   - 检查SEO关键词

---

### 2.4 配图阶段

**工具**：ChatGPT

**步骤**：

1. **配图生成**
   - 使用 ChatGPT 生成配图：
     ```
     请为以下文章生成配图：
     文章主题：{主题}
     图片风格：{简约清新/专业商务}
     图片数量：{1-3张}
     ```

2. **图片优化**
   - 调整图片尺寸
   - 添加图片说明

---

### 2.5 发布阶段

**工具**：Medium、小红书、Threads、Instagram

**步骤**：

1. **平台选择**
   - 深度文章 → Medium
   - 图文内容 → 小红书
   - 轻量内容 → Threads、Instagram

2. **内容适配**
   - 根据平台特点调整内容格式
   - 添加平台特定元素（hashtags等）

3. **发布时间**
   - 小红书：20:00-22:00
   - Instagram：21:00-23:00
   - Medium：周末上午

## 四、内容质量标准

### 4.1 底层逻辑专栏

| 维度 | 标准 |
|------|------|

| 案例 | 至少1个真实案例 |

| 完整性 | 覆盖行业全貌 |

## 十一、进阶技巧

### 1. 内容矩阵策略

建立内容矩阵，覆盖不同层次：

- **顶层**：深度白皮书（权威性）
- **中层**：底层逻辑专栏（专业性）
- **底层**：长尾搜索内容（流量）

### 2. 内容复用策略

一次创作，多平台复用：

- 深度文章 → Medium
- 精简版 → 小红书
- 金句版 → Threads
- 图片版 → Instagram

### 3. 内容迭代策略

持续迭代，提升质量：

- 发布后收集反馈
- 根据数据优化内容
- 定期更新旧内容

### 4. 内容联动策略

建立内容联动：

- 白皮书 → 专栏文章
- 专栏 → 长尾内容
- 长尾 → 深度文章
