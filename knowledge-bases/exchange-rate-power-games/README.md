# 外汇市场与汇率博弈：价格、权力与边界

面向普通大众的单主题知识库，以一家九十天后需支付一百万美元的中国进口商为贯穿案例，解释汇率如何由真实支付、资产配置、融资约束、政策承诺与市场反馈共同形成。

## 页面

- `main.html`：相对价格与多方力量
- `feedback-mechanism.html`：预期、订单、库存与反馈
- `policy-and-risk.html`：制度、政策工具与企业风险管理
- `sources.html`：一手来源、统计口径与站内延伸

## 设计

Hallmark `Narrative Workflow` 宏观结构，Riso 风格暖纸与钴蓝/朱红校记，采用报刊式导航、纵向因果轨、响应式布局和系统深色模式。核心内容与叙事契约分别记录在 `content-manifest.json` 和 `content-review.json`。

## 边界

内容用于金融教育，不提供汇率预测、产品推荐或交易指令。市场数据和政策安排会变化，使用时应回到来源页链接的发布机构核对最新版。
