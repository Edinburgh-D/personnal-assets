# 拉丁文与欧洲学术传统

面向普通大众的四页知识库，以牛顿 1687 年拉丁文《自然哲学的数学原理》为贯穿案例，解释拉丁文如何依靠教育、文本、翻译、大学与印刷成为跨地域学术语言，并判断它在民族语言兴起后如何转型。

## 页面

- `main.html`：共同语言的直觉、范围与代价
- `institutions.html`：学校、大学、翻译、印刷与资格机制
- `transformation.html`：民族语言、近代转型与现代遗产
- `sources.html`：馆藏、研究项目、学术文献与站内连接

内容规划见 `content-manifest.json`，逐页读者复核见 `content-review.json`。共享视觉资源为 `tokens.css`、`styles.css` 与 `script.js`。
