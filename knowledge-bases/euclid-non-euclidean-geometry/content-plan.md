# 欧几里得与非欧几何知识库内容规划

## 1. 需求确认

| 项目 | 决定 | 来源 |
|---|---|---|
| 主题 | 从欧几里得公理体系出发，解释第五公设、双曲几何、椭圆几何、模型与现代应用 | 话题池随机抽取 |
| 类型 | 单一主题型 | 话题池标注 `single` |
| 主读者 | 普通大众 | 自动化任务默认值 |
| 重点 | 理论、历史、应用、批判均衡 | 自动化任务默认值 |
| 特殊功能 | 深色模式、搜索、书签、阅读进度、响应式、打印与 SEO | 用户授权全部启用 |

## 2. 领域与深度协议

| 项目 | 规划 |
|---|---|
| 主聚类 | A：形式/分析型 |
| 次聚类 | C：社会/文化型（数学史与认识论转变） |
| 复杂度 | 中等 |
| 页数下限 | 5 个子页面 + 双聚类加成 1 页 |
| 实际结构 | 1 个总览 + 6 个主题页 + 1 个来源页，共 8 页 |
| A 类强制项 | 精确定义、前提→推导→结论、范式对比、假设与边界条件 |
| C 类强制项 | 历史演变时间线、文化语境、意义流变与反普世主义提醒 |
| 表达策略 | 保留必要公式，同时用地图、球面、马鞍面和导航类比解释 |

## 3. 页面结构

| 页面 | 主要任务 | 广度维度 | 关键组件 |
|---|---|---|---|
| `main.html` | 建立三种几何的空间地图与阅读路线 | 机制、人群、反思 | 交互式 SVG 地图、比较表、概念索引 |
| `euclid-foundations.html` | 公理化方法与《几何原本》的证明机器 | 历史、机制 | 公理表、命题依赖图 |
| `fifth-postulate.html` | 第五公设为何特殊，以及失败的证明如何催生新几何 | 历史、争议 | 时间线、等价命题、误区折叠 |
| `hyperbolic-geometry.html` | 负曲率、无穷多平行线、角和与面积 | 机制、应用 | 庞加莱圆盘 SVG、推理链 |
| `elliptic-geometry.html` | 正曲率、无平行线、大圆测地线 | 机制、地域 | 球面路线 SVG、欧/椭圆对比 |
| `models-consistency.html` | 模型、相对一致性与“真”的重新定义 | 争议、反思 | 模型映射、范式对比表 |
| `modern-applications.html` | 相对论、网络、层级嵌入与数据表示 | 应用、人群、预测 | 应用矩阵、边界条件 |
| `sources.html` | 原典、论文、阅读建议和置信度说明 | 反思 | 注释书目、来源分级 |

## 4. 可视化规划

- 主页面：五节点几何知识地图；节点可点击进入对应页面。
- 双曲几何页：庞加莱圆盘模型，展示测地线与边界。
- 椭圆几何页：球面大圆与两点之间多条弧线。
- 所有 SVG 使用 `viewBox`、`role="img"`、`aria-label`、`title`，并提供文字 fallback。

## 5. 可信来源

- 欧几里得《几何原本》第一卷与第五公设：Clark University 的 David Joyce 数字版。
- 罗巴切夫斯基《平行线理论的几何研究》：公版英译本扫描。
- 黎曼 1854 年就职演讲：Trinity College Dublin 历史数学档案。
- 贝尔特拉米 1868/1869 年非欧几何模型论文：Numdam 原刊数字档案。
- 希尔伯特《几何基础》：Project Gutenberg 公版英译本。
- 爱因斯坦 1916 年广义相对论论文：University of Pittsburgh 教学档案中的英译本。
- Nickel 与 Kiela 2017 年庞加莱嵌入论文：NeurIPS 论文库。
- Krioukov 等 2010 年复杂网络的双曲几何论文：arXiv 原论文。

## 6. 反幻觉边界

- 不给出无法核实的“首次发现”绝对归属；高斯、鲍耶、罗巴切夫斯基的贡献按“独立发展/未公开/发表”区分。
- 不把地球球面直接等同于完整的椭圆平面；明确“球面几何”与“对径点识别后的椭圆几何”的差别。
- 不声称现代应用都必须使用非欧几何，只说明其在特定建模条件下的作用。
- 数学推导标注前提与边界；涉及现代研究结果时链接论文原文。

## 7. 设计系统

- Hallmark：Map / Diagram 宏结构。
- 主题：Almanac，暖纸张、中性墨色、少量圆规红作为强调色。
- 导航：N3 侧轨，移动端折叠为顶部菜单。
- 页脚：Ft1 Mast-headed。
- 插图：E5 Tier-B 手工 SVG；无外部图片、字体或运行时依赖。
- 动效：仅节点淡入、主题切换和交互反馈；支持 `prefers-reduced-motion`。
