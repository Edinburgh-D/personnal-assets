# 黄金比例与数学之美

面向普通大众的三页单主题知识库，按“建立直觉 → 解释机制 → 形成判断”展开。

- 入口：`main.html`
- 页面：比例的直觉、方程与递归、证据与边界
- 视觉：Hallmark Long Document / Atelier，暖纸、尺规线与教学型 SVG
- 依赖：无构建步骤；浏览器直接打开即可阅读
- 数据契约：`content-manifest.json`
- 读者复核：`content-review.json`

核心材料来自欧几里得《几何原本》的相关定义与命题、Wolfram MathWorld 的斐波那契数资料，以及有关黄金比例误解、鹦鹉螺测量和审美偏好的同行评议研究。完整链接列在各页末尾。
