# 量子计算入门

面向普通大众的单主题知识库。三章依次从测量与相位建立直觉，用四门搜索实验解释线路机制，再以逻辑资源、纠错、经典基线和密码迁移形成现实判断。

入口：`main.html`

## 文件

- `main.html`：量子比特、叠加、振幅、相位与测量直觉
- `circuits-and-interference.html`：量子门、目标标记、干涉、纠缠与采样
- `limits-and-usefulness.html`：适用问题、纠错边界、现实价值与密码迁移
- `sources.html`：原始论文、官方课程和标准
- `content-manifest.json`：叙事契约
- `content-review.json`：最终读者复核

## 设计

Hallmark editorial / Split Studio / Studio。页面采用冷白实验纸、深绿信号和左右交替的“解释—证据”结构；图形直接承担状态、线路和证据边界的说明，不使用装饰性数据或通用渐变卡片墙。
