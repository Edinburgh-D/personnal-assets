# 时装周与秀场文化

面向普通大众的单主题知识库。三章依次解释时装周的制度结构、秀场的制作机制，以及观看与评价秀场时需要纳入的权力、劳动和环境边界。

入口：`main.html`

## 文件

- `main.html`：时装周的日历、准入与媒介结构
- `making-a-show.html`：选角、造型、走位、空间、声音与镜头
- `reading-the-runway.html`：形式判断、劳动边界与环境责任
- `sources.html`：一手机构材料与延伸阅读
- `content-manifest.json`：叙事契约
- `content-review.json`：最终读者复核

## 设计

Hallmark editorial / Narrative Workflow / Riso。页面以暖纸、黑墨、朱红套印和细长“跑道线”为视觉语言，不使用虚构摄影或装饰性数据。
