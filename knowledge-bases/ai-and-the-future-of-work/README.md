# AI会取代你的工作吗

面向普通大众的单主题知识库，以任务分解、组织采用和个人判断三层解释 AI 对工作的影响。

入口为 `main.html`，叙事页依次为：

1. `main.html`：区分职业、任务、暴露与替代；
2. `from-capability-to-jobs.html`：解释技术能力如何经过组织和市场形成岗位变化；
3. `map-your-work.html`：把宏观理解迁移到个人工作地图；
4. `sources.html`：列出来源与证据边界。

设计采用 Hallmark `Map / Diagram` 宏观结构与静态 `Terminal` 主题。页面支持响应式布局、系统深浅色偏好、手动主题切换、键盘焦点与打印。
