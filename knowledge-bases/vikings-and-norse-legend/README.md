# 维京人与北欧传奇

面向普通大众的单主题历史知识库，按“辨认海上社会—解释权力机制—判断传奇证据”的顺序，形成约 20–30 分钟的连续阅读路径。

## 阅读顺序

1. `main.html`：海上的北方人
2. `ships-and-power.html`：船、财富与权力
3. `saga-and-evidence.html`：传奇留下了什么
4. `sources.html`：证据、来源与延伸阅读

正文以 Skuldelev 船组和文兰证据链为贯穿案例。内部叙事契约仅保存在不可见的 `template[data-narrative]` 中，来源页列出正文判断对应的权威材料与证据边界。
