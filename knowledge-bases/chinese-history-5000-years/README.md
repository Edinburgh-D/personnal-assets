# 中国上下五千年历史 知识库

## 概述

本知识库系统介绍中国从远古到近现代约五千年文明发展的基本脉络，涵盖政治制度、经济结构、思想文化和民族关系等核心维度。

## 基本信息

- **主题**：中国上下五千年历史
- **类型**：多分支型 (multi-branch)
- **目标读者**：普通大众（历史爱好者、学生、希望系统了解中国历史的读者）
- **深度等级**：L2 标准（面向"大概简介"需求的通史式介绍）
- **生成时间**：2026-08-02
- **技能**：knowledge-base-generator v2.1.0

## 来源策略

内容基于中国历史学通用知识体系（综合整理），代表性引文出自古代文献（一手资料），争议议题（夏朝年代、焚书坑儒规模等）已在文中标注不确定性。近现代部分取第三方视角，避免单一叙事。
