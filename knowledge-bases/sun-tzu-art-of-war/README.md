# 孙子兵法知识库

面向普通大众的四页历史与军事思想知识库。三页叙事正文依次解释全书的判断起点、十三篇的运行机制，以及作者、版本与现代迁移的边界；`sources.html` 汇总原典、考古和版本来源。

- 入口：`main.html`
- 架构：multi-branch
- 视觉：历史报刊与行军簿册
- 主题：支持系统深色模式与手动切换
- 验证：使用 knowledge-base-generator v6.0.0 的 `validate-output.ps1`

河口小国是帮助读者理解机制的虚构教学案例，不对应具体历史战争。正文对传统作者叙事、出土材料、现代解释和类比推论分别标注，避免用一种证据替代另一种证据。
