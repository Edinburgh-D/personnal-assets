# 柏拉图《理想国》知识库

- 架构：单一主题，3 个叙事页与 1 个来源页。
- 读者：普通大众。
- 阅读路径：正义问题与建城方法 → 城邦与灵魂的秩序机制 → 洞穴、政体与现代判断边界。
- 视觉：Hallmark Long Document / Almanac，以城邦平面图与灵魂剖面图的双重尺度组织信息。
- 来源：Perseus、MIT Internet Classics Archive、Stanford Encyclopedia of Philosophy、Internet Encyclopedia of Philosophy。

正文以斯特凡页码定位原典，不把解释性概括写成柏拉图的逐字引文。
