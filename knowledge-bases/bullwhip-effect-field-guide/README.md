# 供应链牛鞭效应：从订单波纹到协同治理

面向普通大众的单主题知识库。三篇叙事页沿“建立直觉—解释机制—形成判断”推进，并附一篇来源与概念边界页。

- 入口：`main.html`
- 架构：single-subject
- 视觉：Hallmark Long Document / Almanac，订单振幅轨道隐喻
- 内容契约：`content-manifest.json`
- 读者复核：`content-review.json`

页面使用原生 HTML、CSS 与 JavaScript，不依赖构建步骤。`tokens.css` 保存局部设计 token，`styles.css` 只通过 token 使用颜色与字体。
