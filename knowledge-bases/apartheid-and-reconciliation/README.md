# 种族隔离与和解之路

面向普通大众的单主题知识库，以南非为核心个案。三卷叙事依次解释种族隔离的制度结构、制度退出的多重机制，以及真相、责任、赔偿与物质修复之间的关系；`sources.html` 集中列出权威来源与法律边界。

## 页面

- `main.html`：隔离如何成为制度
- `dismantling.html`：从僵局到宪法桥梁
- `reconciliation.html`：和解不是结案
- `sources.html`：权威来源与法律边界

## 设计

Hallmark `Map / Diagram` 宏观结构，`Almanac` 主题。视觉以法律卷宗、制度连接图与低饱和司法色为主，不使用照片、通用渐变或装饰性统计。

## 内容边界

页面提供公共教育，不构成法律意见。涉及国际法中的种族隔离罪时，正文区分道德类比、社会结构分析与法律指控，并要求按具体要件、事实、证据与管辖进行判断。
