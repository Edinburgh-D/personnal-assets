# 日元套息交易知识库

面向普通大众的单主题知识库，以一亿日元教学算例贯穿“建立直觉 → 拆解收益 → 判断平仓风险”的连续路径。

## 页面

- `main.html`：交易结构与直觉模型
- `mechanics.html`：收益、汇率、杠杆与保证金
- `unwind.html`：市场回流、2024 年案例与判断框架
- `sources.html`：日本银行、BIS 与 IMF 的来源和口径
