# Web3 与去中心化

面向普通大众的单主题知识库，以创作者合作社为贯穿案例，沿“概念地图 → 交易机制 → 判断边界”形成连续学习路径。

- 入口：`main.html`
- 叙事页：3 页
- 参考页：`sources.html`
- 内容契约：`content-manifest.json`
- 读者复核：`content-review.json`
- 设计：Hallmark Long Document / Almanac，N3 side rail，Ft4 dense colophon

页面使用纯 HTML、CSS 与少量原生 JavaScript。主题偏好同时写入本库键 `web3-kb-theme` 与仓库兼容键 `kb_darkMode`。
