# 核废料处理

面向普通大众的单主题多页面知识库。叙事路径从废物流分类出发，进入湿式与干式贮存、多重屏障和深地质处置机制，最后给出检验具体项目的证据与治理框架。

## 页面

- `main.html`：辨认废物流，区分贮存与处置
- `containment-and-disposal.html`：解释热管理、屏蔽、包容和地质隔离
- `judging-a-plan.html`：检验安全论证、健康边界、监管与跨代责任
- `sources.html`：一手来源与状态核对说明

内容依据 IAEA 安全标准、WHO 与 UNSCEAR 健康资料、国家监管资料及芬兰项目公开状态编写，最近核对日期为 2026-10-19。
