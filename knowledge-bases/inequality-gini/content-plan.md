# 贫富差距与基尼系数：内容计划

## 读者与任务

面向具有一般社会经济常识、希望正确阅读不平等指标的读者。目标不是背诵阈值，而是在 20–30 分钟内建立一条可复用的分析链：先界定分配对象，再理解测量机制，最后完成跨地区、跨时间和政策前后的专业判断。

## 叙事主线

1. **定对象**：同一句“差距扩大”，可能指工资、市场收入、可支配收入或财富，也可能以个人或家庭为单位。先把口径写完整。
2. **懂机制**：用五户虚拟家庭的同一组收入贯穿洛伦兹曲线、面积公式与 0.40 的计算，再解释统计性质与局限。
3. **会判断**：将基尼系数与中位数、分位份额、贫困、再分配和流动性指标组合；建立可操作的审查清单。

## 视觉与交互

- Hallmark：Editorial / Stat-Led / Studio；N6 报刊式刊头；Ft2 单线页脚。
- 主色为纸张白、墨黑与克制的深绿；数据重点使用衬线大字，不使用渐变与装饰性卡片。
- 手工 SVG 绘制洛伦兹曲线，同时提供数据表作为无障碍替代。
- 交互仅保留移动导航与明暗主题切换；关闭 JavaScript 后正文和导航仍然可读。

## 事实边界

- 五户收入案例完全是假设数据，只用于演算，不影射真实地区。
- 国际定义与可比性依据世界银行和 OECD 官方资料。
- 中国实例只引用国家统计局公布的 2024 年全国居民人均可支配收入均值、中位数与调查说明，用来说明“中位数/均值并不等于基尼系数”，不据此推断中国基尼系数。
