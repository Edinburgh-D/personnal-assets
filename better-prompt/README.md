# 提示词优化助手

基于 AI 的智能提示词评估与优化工具

## 功能特性

- ✅ **四维度评估**：清晰度、准确度、深度、相关性
- ✅ **智能优化**：提供具体的改进建议和优化后的提示词
- ✅ **一键复制**：快速复制优化后的提示词
- ✅ **历史记录**：自动保存最近 20 条记录
- ✅ **响应式设计**：支持桌面和移动设备

## 快速开始

### 前提：

1. 给小鲁班发送:获取 apikey
2. 得到自己账号的 apikey，填入到 server.py 文件里的第 9 行

### 方法一：使用启动脚本（推荐）

1. 双击 `start.bat` 文件
2. 等待依赖安装完成
3. 服务器启动后，浏览器访问 `http://localhost:5000`

### 方法二：手动启动

1. 安装 Python 依赖：

```bash
pip install -r requirements.txt
```

2. 启动代理服务器：

```bash
python server.py
```

3. 在浏览器中打开 `index.html` 文件

## 使用说明

1. 在左侧输入框中输入你的原始提示词
2. 点击"开始优化"按钮
3. 等待 AI 分析和优化（通常需要 10-30 秒）
4. 查看右侧的评估结果和优化建议
5. 点击"复制优化后的提示词"按钮快速复制

## 评估标准

### 清晰度（1-5 分）

提示是否清晰地传达了其意图，没有歧义？

### 准确度（1-5 分）

提示是否重点突出、具体地描述了预期结果？

### 深度（1-5 分）

提示是否考虑到了请求的细微差别，避免了流于表面的细节？

### 相关性（1-5 分）

提示是否与预期任务或问题一致，没有偏离？

## 常见问题

### Q: 为什么需要代理服务器？

A: 由于浏览器的 CORS（跨域资源共享）限制，前端无法直接调用外部 API。代理服务器作为中间层，解决跨域问题。

### Q: 优化速度慢怎么办？

A: AI 模型的响应时间通常在 10-30 秒，这取决于网络状况和服务器负载。请耐心等待。

### Q: 历史记录存在哪里？

A: 历史记录保存在浏览器的 localStorage 中，最多保存 20 条记录。清除浏览器数据会删除历史记录。

### Q: 支持哪些浏览器？

A: 支持所有现代浏览器（Chrome、Firefox、Safari、Edge 等）

## 注意事项

- 请确保网络连接正常
- API 密钥仅供演示使用，请勿滥用
- 建议使用 Chrome 或 Edge 浏览器获得最佳体验
